# chilldivision-links
Social links page for Chill Division, served at https://chilldivision.co.nz/links/.

## Adding a link
Paste `template.txt` under the right month in `index.html` (newest first), then fill in the address and the title.
Start a title with ` - ` to set it in under the link above it.

## Styling
The page uses the main website's stylesheet and script (`../css/site.css`, `../js/site.js`), so it has to sit in
the website's `links/` folder. `links.css` styles the list and `links.js` adds the filter box.
